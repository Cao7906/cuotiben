AI 识别设置

已接入智谱 AI 双模型：glm-4v-flash 拍照识别，glm-4-flash 生成解析与同类题。密钥只保存在服务端 config.json，不会出现在浏览器里。未启动本地服务时自动回退演示模式。

智谱免费双模型：glm-4v-flash 逐张识别图片 → glm-4-flash 生成分步解析与举一反三。视觉模型单次只支持 1 张图，多张照片会自动逐张识别后合并。
带图片的请求会强制走视觉模型，图片按标准 image_url 结构发送（content 里的 type 只有 text / image_url），避免文本模型拒绝图片而报 1210。

数据管理

所有错题保存在本机浏览器（IndexedDB），不会上传到任何服务器；建议定期导出备份。

添加到桌面

手机浏览器打开本页后：Android / Chrome 点击右上角菜单 →「添加到主屏幕 / 安装应用」；iPhone / Safari 点击分享 →「添加到主屏幕」。之后可全屏离线打开。

支持离线查看已录入的错题；AI 识别与举一反三需要联网。

使用说明

纯静态网页应用，零第三方依赖，数据只存在本机浏览器。
版本 1.0 · 适用初中各学科

启动：双击 start.bat（Windows）或运行 node server.js，浏览器打开 http://localhost:5173 。直接双击 index.html 也能用，但无法安装到桌面。

AI 配置：已生成 config.json（智谱免费双模型）。更换密钥或模型请编辑该文件后重启服务；也可在本页选「浏览器直连」自行填写。自检命令：node tools/check_zhipu.js。

手机使用：让手机与电脑处于同一 Wi-Fi，用手机浏览器访问 http://电脑局域网IP:5173 ，再「添加到主屏幕」。
